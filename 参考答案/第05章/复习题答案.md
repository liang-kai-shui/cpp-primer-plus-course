## 任务 1：实验应看到什么

1. 01 的循环体执行 3 次，条件检查 4 次；`i < 0` 时为 0 次、1 次。最后一次条件为假也算检查。
2. 02 输出 0!=1、1!=1、5!=120、10!=3628800。乘积从 1 开始，若从 0 开始则全部变为 0。
3. `*p++` 取旧位置的值、移动指针；`(*p)++` 增加当前元素；`*++p` 先移再取值。程序里有两次移动，最后到第三个元素，没有越界。
4. 反向输出分别是 `cba`、空行、`b a`。两个字符数组地址不同但内容相等；`strcmp` 相等为 0，不等时只依赖结果的正负。
5. `while` 可以零次，`do...while` 正常执行至少一次；值变量复制元素，引用变量修改原元素。
6. 输入 `A b\n#`，07 数到 2，08 数到 4；09 不使用哨兵，`#` 也是普通正文字符。统计单位是从文本流读出的单字节字符，不是 UTF-8 汉字数量。
7. 行合计 60、150；列合计 50、70、90；总计 210。行合计的初值应位于每次外层迭代中。

### 热身A：条件决定进入次数

| 改动 | 输出 | 原因 |
|---|---|---|
| 从0开始，i<1 | `0` | i更新为1后条件为假 |
| 从0开始，i<0 | 无正文 | 第一次检查就失败 |
| 从0开始，i<=3 | `0 1 2 3` | 等于3时仍成立 |
| 从1开始，i<=3 | `1 2 3` | 起点不再包括0 |

长度3的数组只有下标0、1、2。单纯输出i=3合法，并不意味着访问a[3]合法。实验验证的是循环次数，数组边界还需要单独检查。

### 热身B：空循环与普通代码块

第一段输出三次Hello；第二段只输出一次。

```text
for (...);    ← 这个分号已经构成空循环体
{ ... }       ← 循环结束后才执行的独立代码块
```

花括号靠缩进摆在for下面，并不会变成它的循环体。编译器可能提示空体或缩进误导；即使某版本没有警告，也不改变执行规则。

### 热身C：累计值从哪里带进下一轮

| 当前n | 循环外初始化：进入→离开 | 每轮内部初始化：进入→离开 |
|---|---|---|
| 1 | 0→1 | 0→1 |
| 2 | 1→3 | 0→2 |
| 3 | 3→6 | 0→3 |

因此分别输出 `1 3 6` 和 `1 2 3`。累计变量放在循环外，上一轮留下的值才能继续使用；内部版本每轮重新创建并清零。

### 热身D：副本与别名

示例中的原数组为70、80、90。第一轮值循环输出copy=75、85、95，但原数组仍是70、80、90。第二轮用引用才真正改成75、85、95。

将第二轮也改为 `int score` 后，最终数组仍是70、80、90。不要被循环体内打印的75误导：那可能只是副本的值。

`int& score` 中的&说明“score是一个已有int的别名”；`&scores[0]` 中的&是表达式，取得元素地址。它们在不同语法位置，含义不同。

### 热身E：读取和统计是两步

| 输入字符 | 07的逐词字符提取 | 08的get读取 | 是否计数 |
|---|---|---|---|
| A | 读到 | 读到 | 两者计数 |
| 空格 | 跳过 | 读到 | 只有08计数 |
| b | 读到 | 读到 | 两者计数 |
| 换行 | 跳过 | 读到 | 只有08计数 |
| # | 读到 | 读到 | 两者都先结束，不计数 |

因此07为2、08为4。立即#得到0；直接EOF也得到0。09没有#规则，它把成功读到的#当普通字符统计。比较文件输入时必须控制文件末尾是否有换行。

## 任务 2：逐步推演

- A：`0 3 6 9`；更新到 12 后条件为假。
- B：`6 8 final=10`。初始 5，条件先加到 6，体内输出旧值 6 后增到 7；条件加到 8，输出后增到 9；条件加到 10，退出。
- C：`8 final=9`。先输出 8；条件用旧值 8 比较，结果为假，但后置自增仍把 k 变成 9。
- D：`2 4 6`。`x` 是副本；要修改数组可用 `int& x`。
- 空字符串：初值 i 为 0，`i > 0` 为假，没有任何元素访问；不先计算 `size()-1`。

### B再拆成表格：条件里的自增也会发生

| 条件前j | `++j`后j | 是否小于9 | 体内打印 | 体内`j++`后 |
|---|---|---|---|---|
| 5 | 6 | 是 | 6 | 7 |
| 7 | 8 | 是 | 8 | 9 |
| 9 | 10 | 否 | 不进入 | 保持10 |

最后一次条件虽然失败，条件里的++j已经执行。因此final是10。日常代码更建议让更新位置清楚；这题用来读懂表达式，不要求照着写复杂循环。

### C为什么只执行一次却加了1

do先执行体，输出8。之后 `k++<5` 使用旧值8比较，结果为假；后置自增仍然将k改为9。两个问题要分开问：“比较使用哪个值？”和“变量最终变成哪个值？”

## 任务 3：修正

1. `i <= 3` 会写 `a[3]`，越界；改为 `i < 3`。
2. `while` 后的分号使循环体为空，n 一直为 1，永远到不了后面的块；去掉分号。
3. 把读取放到条件：`while (std::cin.get(ch)) { ++count; }`，成功一次计数一次。
4. 使用 `std::strcmp(a,b)==0`，或换为 `std::string` 后用 `==`。
5. 两个修改没有规定的先后顺序，行为未定义；把修改拆成独立语句并明确需要的计算含义。编译器某一次输出不能证明程序正确。

### A. 闭区间求和：逐轮加进同一个总量

完整程序：[ex1.cpp](代码/ex1.cpp)。核心框架是：

```cpp
long long total = 0;
for (int value = lower; value <= upper; ++value) {
    total += value;
}
```

这段假设lower、upper已经读入并通过题目范围检查；不能把检查删去后宣称它适用于任意int上下界。

- lower和upper保存输入，value负责遍历，不必破坏原来的边界。
- total从0开始，因为还没加任何数；放在外面，因为要跨轮保留。
- `<=`包含上界。2到4逐轮总和是2、5、9。
- 5到5只有一轮；−2到2逐轮总和是−2、−3、−3、−2、0。
- 用long long是为了让允许范围内的累计结果装得下。类型要按结果范围选，不只看单个输入有多小。

常见错误是把total每轮清零、用 `<` 漏掉上界，或先算再检查下界是否大于上界。先用小区间定位问题，再跑大边界。

### B. 阶乘表：第i项从第i−1项接过来

完整程序：[ex2.cpp](代码/ex2.cpp)。

```cpp
facts[0] = 1;
for (int i = 1; i <= n; ++i) {
    facts[i] = facts[i - 1] * i;
}
```

| i | 前一项 | 乘数 | 当前项 |
|---|---|---|---|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 2 | 2 |
| 3 | 2 | 3 | 6 |
| 4 | 6 | 4 | 24 |

固定数组101项覆盖下标0到100。n=0时计算循环零次，但输出仍应包含facts[0]。n=3输出1、1、2、6，分别对应0!、1!、2!、3!。

为什么不用int？阶乘增长很快，远早于100!就超出普通整数范围。long double用于保存数量级，不代表它可以精确保存100!的每一个整数位。使用科学计数法输出是合理的。

若起始项设为0，后续全部为0；若计算从i=0开始，就会读到不存在的facts[-1]。这两处不是改输出格式能修好的。

### C. 增长比较：每过一年，更新三件事

完整程序：[ex3.cpp](代码/ex3.cpp)。参考代码使用do...while，让第一年必定发生：

```cpp
do {
    simple += 10.0;
    compound *= 1.05;
    ++year;
} while (compound <= simple);
```

| 年份 | A | B | 继续吗 |
|---|---|---|---|
| 0 | 100 | 100 | 先进入第一年 |
| 1 | 110 | 105 | 是 |
| 2 | 120 | 110.25 | 是 |
| 26 | 360 | 约355.57 | 是 |
| 27 | 370 | 约373.35 | 否 |

A的增量来自**初始100**，所以每年固定加10；B的增量来自**当前值**，所以每年乘1.05。若把A也写成乘1.10，就变成另一道题，B也不会按本题结果超过。

初始相等不能直接判定问题完成；题目问经历增长后第一次严格超过。相等仍要继续，所以条件含等号。

### D. 三年销量：两种累计量的寿命不同

完整程序：[ex4.cpp](代码/ex4.cpp)。

```text
grand_total=0            ← 三年共用一次
每一年：
    year_total=0         ← 本年重新开始
    每个月：
        读sales[year][month]
        year_total加上它
    输出year_total
    grand_total加上year_total
最后输出grand_total
```

每月都加进year_total以后，不要又把同一个月直接加进grand_total，再在年末加year_total，否则统计两遍。

第一年每月1得到12；第二年每月2得到24；第三年每月3得到36；三年总计72。若年合计误放在最外面且不清零，就可能输出12、36、72，显示的是逐年累计而不是各年的合计。

year从0到2，month从0到11，共读取3×12=36格。人的“第1年”对应下标0，显示提示时可以用year+1，但访问数组仍用year。

### E. 单词计数：哨兵检查必须在计数之前

完整程序：[ex5.cpp](代码/ex5.cpp)。参考条件将两个要求连在一起：

```cpp
while ((std::cin >> word) && word != "done") {
    ++count;
}
```

先判断读取是否成功；失败时短路，既不比较旧word，也不进入体内。成功后再看是不是done。

| 输入步骤 | 读取结果 | 是否为done | count |
|---|---|---|---|
| one | 成功 | 否 | 1 |
| two | 成功 | 否 | 2 |
| done | 成功 | 是 | 保持2，结束 |
| three | 不再尝试 | — | 保持2 |

也可以用 `while(cin>>word)`，体内先if检查哨兵、break，再++count。更展开的写法便于初学者看顺序，结果同样正确。

Done和done!不等于done；逐词提取会跳过空白，但不会自动忽略大小写和标点。

### F. 三角形：外层管行，内层管每行的两段

完整程序：[ex6.cpp](代码/ex6.cpp)。

```cpp
for (int row = 1; row <= n; ++row) {
    for (int dots = 0; dots < n - row; ++dots) std::cout << '.';
    for (int stars = 0; stars < row; ++stars) std::cout << '*';
    std::cout << '\n';
}
```

row是从1开始的“第几行”，不是数组下标。每行 `(n-row)+row=n` 个字符，所以右边界对齐。

n=3为：

```text
..*
.**
***
```

n=1时打印点的循环零次，打印一个星，再换行。换行必须在两个内层循环之后；若每打印一个点都换行，就不再是三角形。

## 任务 5：过关要点

1. 从 `size()` 开始，条件 `i > 0`，读取 `s[i-1]`，访问前保证 i 大于 0。
2. `while (std::cin.get(ch))`；读取成功才处理，预先看 EOF 状态可能比最后一次读取早一步。
3. 外层列 0–2，内层行 0–1，访问 `a[row][col]`。外层改变遍历顺序，不改变数组形状。
4. 前置提供新值，后置提供旧值，两者都修改变量；值循环变量是副本，引用循环变量是当前元素的别名。
