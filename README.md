## 一、这份材料是什么

它不是教材的替代品，而是**教材的"陪读笔记"**：

| 你会得到     | 说明                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------- |
| **附录**     | 两篇打地基的文章：《零基础起飞》（电脑最基本概念）和《术语表》（所有专有名词的人话解释） |
| **讲义**     | 每一课一份。教材里讲得抽象的地方，这里用白话重讲；教材里略过的基础，这里补上             |
| **练习**     | 每课一套，含**教材原题**（复习题 + 编程练习）和**动手实验**                              |
| **参考答案** | 编程练习的完整代码 + 复习题答案，附思路说明和**常见错误的订正**                          |
| **示例代码** | 讲义里引用的每个程序，都可以直接编译运行                                                 |
| **网页版**   | `docs/` 目录，**双击 `index.html`** 就能在浏览器里读，不需要装任何软件                   |

### 关于这份材料的写作原则

学校老师上课常常一上来就是一堆专有名词：**"变量""函数""编译""指针"**，
但不讲**它是什么、为什么需要它、它怎么实现的**，学生听完一头雾水。

**这份材料刻意不那样做。** 规矩是：

> ### 每个专有名词第一次出现时，必须先说清楚三件事
>
> 1. **这是什么**（用一句人话）
> 2. **为什么需要它**（它解决了什么问题；如果没它会怎样）
> 3. **打个比方**（用生活里的东西类比）
>
> 然后才往下讲怎么用。

如果你读某一段发现"这里突然冒出一个没解释的词"，**那是我们的问题，请记下来**。

## 二、你需要准备什么

### 1. 教材

> 《C++ Primer Plus（第 6 版）中文版》

讲义里所有"教材 pXX"都是指 **PDF 版的页号**（封面算第 1 页），不是书页脚印的页码。

> 💡 如果你手上的 PDF 书签完整，直接用书签跳转最快。

### 2. 编译器

Windows 上最省事的是 **MinGW-w64**（里面就是 GCC）：

```
下载安装后，确认命令行里能用：
g++ --version
```

**Linux / macOS** 一般自带或容易安装：

```bash
# Ubuntu / Debian
sudo apt install g++

# macOS（装了 Xcode Command Line Tools 就有）
xcode-select --install
```

### 3. 编辑器

推荐 **VS Code**（免费）+ 官方扩展 **C/C++**。
新手也可以先用 Dev-C++、Code::Blocks 之类的 IDE，等熟悉了再换。

> ⚠️ **Windows 中文用户注意**：程序输出中文可能乱码。
> 原因和控制台"代码页"有关（《零基础起飞》里讲了原理）。
> 最简单的一次性解法是在程序开头加：
>
> ```cpp
> #include <windows.h>
> int main() {
>     SetConsoleOutputCP(65001);   // 把控制台输出改成 UTF-8
>     ...
> }
> ```
>
> 或者在运行前先执行 `chcp 65001`。

## 三、怎么用（重要）

### 正确的顺序

```
0. （第一次）读《零基础起飞》和《术语表》的开头说明
1. 读讲义         ← 先看"这一课要解决什么问题"
2. 读教材对应页    ← 讲义里标了哪几页精读、哪几页略读
3. 编译运行示例    ← 对照着看现象，改改参数试试
4. 做练习         ← 手敲！不许复制粘贴
5. 对答案         ← 做完再看参考答案
```

### 五条学习纪律

1. **代码必须手敲**，包括示例。复制粘贴等于没学。
2. **报错不要怕，要学会读报错**。编译器已经把"哪里错了、错在哪一行"告诉你了。
   **报错原文从第一行开始读**——第一行是原因，后面的常常只是结论。
3. **先自己想，再看答案**。想不出来把你的思路写下来，那比答案有价值。
4. **改完 bug 要用工具验证，不要用眼睛看**。
   人是看不见"少了一个字母"的（自己写的代码尤其如此）。Linux/macOS 用 `diff`，
   Windows 用 `Compare-Object` 或 `fc`。
5. **题目给的"输入 → 输出"例子，就是你的测试用例**。写完跑一遍对照。
   对不上就先怀疑自己的代码，再怀疑题目。
6. **做完实验要把改过的示例文件改回去**。
   `示例代码/` 里那些文件是"教材"，被改坏了下次就看不懂了。
   **更省事的办法**：做实验时新建一个文件去试，不要直接改示例。

## 六、课程速览

第 4 章内容较多，拆成了四课（A、B、C、D 已完成）。

| 课            | 主题                 | 你会学到                                                                                                                        |
| ------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **第 1 章**   | 预备知识             | 程序是怎么从一段文字变成能运行的软件的；**三类错误的分类框架**（编译错误 / 链接错误 / 运行时错误）——这个框架后面每一课都用得上  |
| **第 2 章**   | 开始学习 C++         | 变量、语句、函数、`cout`/`cin`；重点是**函数原型**和**名称空间**                                                                |
| **第 3 章**   | 处理数据             | 整型家族、`char` 的本质、`const`、浮点数、**整数除法与类型转换的坑**                                                            |
| **第 4 章 A** | 数组与字符串         | 数组其实就是"一排连号的储物柜"；**C 风格字符串的本质是 `'\0'`**；`cin`/`getline` **混合输入的陷阱**；`std::string` 好在哪       |
| **第 4 章 B** | 结构、共用体、枚举   | 怎么把**不同类型**的数据打包成一个整体；**结构声明 ≠ 结构变量**（这是后面学"类"的地基）；`struct` 和 `union` 在内存上的根本区别 |
| **第 4 章 C** | 指针与自由存储空间 | 地址、解引用、`nullptr`、`new` / `delete`、动态数组与所有权 |
| **第 4 章 D** | 指针算术与数组替代品 | 数组与指针的关系、动态结构、存储持续期、`std::array` 和 `std::vector` |
| **第 5 章** | 循环和关系表达式 | for / while / do...while、范围循环、自增、文本输入与 EOF、二维数组 |
| **第 6 章** | 分支语句和逻辑运算符 | if、逻辑短路、cctype、switch、输入失败恢复、文本文件读写 |
| **第 7 章 A** | 函数基础与数组参数 | 原型、按值传递、有效长度、指针区间、const、二维数组、C 风格字符串 |
| **第 7 章 B** | 结构、字符串、递归与函数指针 | 结构值与地址、string/array 对象、递归过程、回调、函数指针数组 |

> 第 5–7 章已按教材正文核对并编写。第 7 章拆成 A、B 两课，配有 22 个示例和 12 道编程任务；第 8 章及以后继续编写。
