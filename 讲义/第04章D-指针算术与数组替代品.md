## 1. 指针算术：按“元素”移动

```cpp
int values[4]{10, 20, 30, 40};
int* p = values;             // 此处数组名转换为首元素地址
std::cout << *p;             // 10
std::cout << *(p + 1);       // 20
std::cout << p[2];           // 30
```

`p + 1` 指向**下一个 `int` 元素**，并非“地址数字加 1 个字节”；实际地址会按 `sizeof(int)` 跨过一个元素。换成 `double*`，则按 `double` 元素移动。`p[i]` 与 `*(p + i)` 在这里表示同一个元素。

```text
values: [10] [20] [30] [40]
         p  p+1  p+2  p+3   p+4（尾后位置，不可解引用）
```

从同一个数组的首元素可以得到指向末尾**后一位置**的指针 `p + 4`，用它作为循环终点；不能写 `*(p + 4)`。也不要越过这个位置形成更远的指针。指针减法、比较大小等操作也应限制在**同一个数组及其尾后位置**，不能拿两个不相干对象的地址随意计算距离。

> ⚠️ `p++` 改变的是 `p` 保存的地址；`(*p)++` 改变的是所指整数的值。括号决定意思，先分别预测再运行。

## 2. 数组和指针相关，但不是同一种类型

在多数表达式里，数组名会转换为首元素指针，因此 `values[2]` 与 `*(values + 2)` 都能取得第三个元素。但“数组就是指针”是错的：

```cpp
int values[4]{10, 20, 30, 40};
int* p = values;

sizeof(values); // 整个数组占的字节数：4 * sizeof(int)
sizeof(p);      // 指针变量自己的大小，与数组长度无关
// values = p;  // 错：内置数组不能整体赋值
```

`sizeof` 用于这里的数组表达式时，不发生数组到指针的转换；`&values` 取得整个数组的地址，其**类型**也不同于 `&values[0]`。两者可能显示同一个起始地址，但 `&values + 1` 会跨过整个数组，`&values[0] + 1` 只跨过一个元素。初学阶段优先用下标读写数组，不必靠复杂指针表达式完成简单任务。

## 3. 指针与 C 风格字符串

```cpp
const char* message = "hello";  // 指向字符串字面量，不能通过它修改字符
char word[] = "hello";          // 自己的可修改数组，末尾含 '\0'
word[0] = 'H';
```

输出 `message + 1` 会从第二个字符开始读到 `\0`，得到 `ello`。`std::strlen(message)` 统计终止符之前的字符数；`sizeof(word)` 包含末尾的 `\0`。**不要把指针直接当成有长度的字符串对象**：它可能指向非字符串数据，也可能在终止符之前失效。

普通文字处理优先用 `std::string`。只有与 C 接口、教材示例或固定格式数据交互时，才需要仔细处理字符指针与终止符。

原书程序清单 4.20–4.22 还演示了 `strcpy`、`new char[]` 和 `delete[]`。阅读时注意：给字符数组分配空间必须包含末尾的 `\0`，复制前目标空间必须足够。写自己的日常文字处理程序时，继续优先用 `std::string`。

## 4. 动态结构与 `->`

```cpp
struct Student { std::string name; int age; };
Student* p = new Student{"Li Ming", 19};
std::cout << p->name;          // 等价于 (*p).name
delete p;
p = nullptr;
```

`p` 是**指向结构的指针**；`*p` 才是结构对象。因此用 `p->name` 访问成员。`*p.name` 不等价：点号先作用于 `p`，而 `p` 是指针，没有 `name` 成员。给动态对象赋值时也要保持 `new` / `delete` 配对；结构中的 `std::string` 成员会在对象销毁时正确处理自身资源。

## 5. 谁决定对象活多久？

| 存储持续期 | 典型写法 | 生存期要点 |
|---|---|---|
| 自动 | 函数里的 `int x{}` | 进入所在代码块创建，离开时结束 |
| 静态 | 全局变量或函数内 `static int count{}` | 一般持续到程序结束 |
| 动态 | `new Student{...}` | 从创建到对应的 `delete` |

“作用域”管**名字在哪里可见**，“生存期”管**对象还在不在**。不要返回局部变量的地址给调用者以后使用；局部对象离开函数已结束生存期。动态对象即使创建它的局部指针离开作用域，也不会自动因指针消失而释放，于是可能泄漏。

## 6. 类型组合：从变量名往外读

教材 4.9 会出现“数组的指针”和“指针的数组”：

```cpp
int* pointers[3];    // pointers 是数组，里面有 3 个 int*
int values[3]{};
int (*whole)[3] = &values; // whole 是指针，指向整个 3 元素数组
```

先看变量名旁的符号：`pointers[3]` 先表明它是数组；`(*whole)` 的括号使 `whole` 先成为指针，再指向 `[3]` 这个数组类型。这里先能辨认即可，实际练习优先用清晰的容器类型。

## 7. `std::array` 与 `std::vector`

| 类型 | 长度 | 可整体赋值 | 常见访问方式 | 何时选用 |
|---|---|---|---|---|
| `int a[3]` | 编译时固定 | 不可 | `a[i]`，不检查边界 | 阅读教材或与旧接口交互 |
| `std::array<int, 3>` | 编译时固定 | 可以 | `a[i]`、`a.at(i)` | 固定数量的元素 |
| `std::vector<int>` | 可在运行时决定或增长 | 可以 | `v[i]`、`v.at(i)`、`v.push_back(x)` | 数量由输入决定或会变化 |

```cpp
#include <array>
#include <vector>

std::array<int, 3> fixed{1, 2, 3};
std::vector<int> growing{1, 2, 3};
growing.push_back(4);
```

三者的 `operator[]` **都不做边界检查**；`std::array` 与 `std::vector` 的 `.at(i)` 会检查并在越界时抛出异常。`std::vector` 管理动态存储空间，普通使用时无需自己 `new[]` / `delete[]`。即使 `vector` 能增长，仍要关注输入是否合理、下标是否小于 `size()`。

> 实用选择：已知固定数量用 `std::array`；数量由输入决定用 `std::vector`。本章手写 `new[]` 是为了理解内存规则，不是推荐日常都手工管理动态数组。
