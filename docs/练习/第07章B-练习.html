第 7 章 B 练习：结构、字符串、递归与函数指针

对应教材 7.6–7.10（PDF 246–266 页），本章复习、编程题在 267–270 页。 题目用课程语言整理，注明教材题号及改编点。完整原题请阅读自备教材。

0. 做题顺序与提交方式

先读 讲义，做口头题和手走题，再按 A、B、C、D、E、F 完成。 代码写到自己新建的 my_code/ex1.cpp 至 ex6.cpp；作答笔记另存，不修改示例或参考程序。

每个任务先填：输入是什么、返回什么、修改什么、失败怎么办。 递归先画过程，函数指针先核对类型，然后再编译。

提交源码、正常和边界测试各至少一组，并写一句解释自己遇到的错误如何解决。 Ctrl+Z 再回车可以在 Windows 终端结束输入。循环题遇到约定的非数字也可停止。

1. 口头题

Q1 同样是 Box 参数，作用是否相同？

void show(Box box);
bool update(Box* box);
void inspect(const Box* box);

分别说明：接收值还是地址？能否通过这个参数修改 main 的 Box？调用时传 package 还是 &package？ update 中把 box 改为 nullptr，main 的 package 是否被删除？

Q2 原生数组与 array 对象

void first(int values[], int count);
void second(std::array<int, 3> values);

两个函数都把第一项设为 0，哪个会改变调用者的元素？解释它们实际收到什么。 把 second 改为接收整个 array 对象的指针，原型和调用各应怎么写？

Q3 递归的三个条件

以 factorial 为例，指出基本情形、问题缩小方式、子调用返回后要做的事。 factorial(0) 有零次调用还是一次调用？负数为什么必须在传入无符号参数前检查？

Q4 函数地址与函数结果

有 double square(double);：

  • square、&square、square(3) 在赋值或调用语境里分别是什么？
  • double (*pf)(double) 与 double* pf(double) 哪个是指针变量？
  • pf 已指向 square，pf(3) 与 (*pf)(3) 的结果是否相同？
  • 为什么 int other(double) 不能直接放进这个 pf？

Q5 指针的两层寿命

某个函数指针指向一个会返回数组元素地址的函数。 调用后得到的 const double* result 是否也指向函数？ 如果它指向 main 的局部数组，是否要 delete？main 的数组销毁后是否还能读？

void trace(int n)
{
    std::cout << "enter " << n << '\n';
    if (n > 0) trace(n - 1);
    std::cout << "leave " << n << '\n';

手写 trace(2) 的六行输出，在每个 leave 旁写“哪个子调用刚刚返回”。 如果把自调用移到两条输出之后，顺序会怎样变？

3. A：箱子体积（ex1）

改编自教材编程练习 3。maker 从原题的字符数组改为 string，保留“按值显示、通过指针修改”的核心。

需求

struct Box {
    std::string maker;
    double height;
    double width;
    double length;
    double volume;
};

void show_box(Box box);
bool update_volume(Box* box);

读一行非空制造商名字，再读高、宽、长三个数。尺寸必须有限、范围 0–1000。计算体积写回原 Box，显示全部成员。 空指针或非法尺寸让 update 返回 false；main 报错并结束，不显示成功结果。

先手算

制造商 Demo，尺寸 2、3、4，体积 24。任意一项为 0，体积为 0，这里视为合法演示输入。

起步步骤

  1. 先定义结构，再声明使用这个结构的函数原型。
  2. main 建立 Box box{}，未填字段初始有确定的值。
  3. getline 接收 maker，>> 接收三项尺寸。
  4. 调用 update_volume(&box)，检查 bool 返回值。
  5. 函数先检查 box，再用 -> 读取尺寸、验证范围。
  6. 全部通过后才写 volume，show_box(box) 按值显示。

自测

Demo 换成带空格的 Water Workshop；尺寸 2、3、4；零尺寸；负尺寸；1001；缺一项；空名字。 再在单独的小实验中调用 update_volume(nullptr)，应得到 false，不执行成员访问。

口头说明： 为什么 show_box 按值能完成显示，而 update_volume 按值不能按本题要求写回？

4. B：四季开支（ex2）

对应教材编程练习 8 的 b 版：用一个结构包住原生数组。本课给出明确数值范围。

struct Expenses { double values[4]; };
bool fill_expenses(Expenses* expenses);
void show_expenses(const Expenses* expenses);

需求

必须读到四项有限开支，每项 0–1000000；按 Spring、Summer、Fall、Winter 显示，再输出 total。 任意一项读取失败或非法，fill 返回 false，main 报错，不显示完整账单。空指针也返回 false。

起步步骤

  1. main 建立 Expenses，并把地址传给 fill。
  2. fill 循环四次，先读到临时变量并验证，再写 expenses->values[i]。
  3. 四次都成功才返回 true。
  4. show 使用同下标的季节名和开支值，每次累加 total。
  5. show 只读，使用 const 指针；遇到 nullptr 直接返回。

自测

输入 预期
100 200 300 400 四季对应显示，total=1000
0 0 0 0 total=0
只有三项后 EOF 报不完整输入，不输出完整账单
-1 2 3 4 报非法范围

思考：fill 在第三项失败时，前两项可能已经写进对象。本题 main 结束，所以不会把半份记录当成功结果。如果要求失败时保留原账单，可以先填临时 Expenses，全部成功后再赋给原对象，这是选做。

5. C：递归阶乘（ex3）

对应教材编程练习 5。

需求

重复读取整数 n，合法范围 0–20，显示 n!=结果。遇到非数字或 EOF 正常结束；读到负数或 21 以上报错结束。 用递归实现 factorial，返回 unsigned long long。

unsigned long long factorial(unsigned int n);

必须先交的纸上过程

用四行写出 factorial(3) 怎样缩到 factorial(0)，再从下往上写返回值 1、1、2、6。 不能只写“因为公式是 n×(n−1)!”。要说明每次调用在等哪个结果。

起步步骤

  1. 先实现 n==0 时返回 1。
  2. 其他合法情况返回 n×factorial(n-1)。
  3. main 用 int 读入，先检查负数和上限，再调用。
  4. 保存或直接输出返回值；每轮回到输入循环。
  5. 不要把调用者的循环写进 factorial，也不要让 factorial 自己读下一道题。

自测

0→1；1→1；5→120；20→2432902008176640000；-1、21 报错；x 正常结束。 一次输入 0 1 5 x 应得到三项结果，而非只算第一项。

选做：写循环版本，对 0–20 逐项比较结果，理解两种重复的差别。

6. D：学生记录与三种显示（ex4）

改编自教材编程练习 9：名字、爱好用 string，固定最多 3 条记录；原题动态分配容量的部分留作选做。

struct Student {
    std::string name;
    std::string hobby;
    int level;
};

int get_students(Student students[], int capacity);
void display_value(Student student);
void display_pointer(const Student* student);
void display_all(const Student students[], int count);

需求

每人依次输入名字一行、爱好一行、等级整数一行。名字允许空格，空名字作为结束标记。等级 0–10。 读下一条名字时 EOF 正常结束；一条记录开始后缺爱好或等级，或等级超范围，报告错误。 返回实际记录数，错误返回 -1。先用按值、指针两种方式逐人显示，再用数组方式显示所有有效记录。

输出分别加 value:、pointer:、array:，方便确认三种接口都调用过。

起步步骤

  1. 建立 Student students[3]{}，count 为 0。
  2. 每轮建一个临时 candidate，getline 读名字。
  3. 名字为空或开始新名字时遇到 EOF，返回已成功记录数。
  4. 读 hobby 和 level，检查等级。

  5. 后忽略当前行余下内容及换行，再准备下一次 getline。

  6. 这一条全部成功后才赋给 students[count]，再增加 count。
  7. main 检查错误，用 i<count 遍历，指针显示调用时给 &students[i]。

测试输入的真实布局

Li Ming
reading books
3
Han
cycling
8

最后一行是空名字，count 应为 2。三个显示函数都应显示这两条数据。

再测第一行就是空行、只输入一条后 EOF、等级 -1 或 11、名字后就 EOF、正好三条。 容量满后停止，不要求再读第四个空名字。

提醒： 函数的 capacity 是可写容量，返回的 count 是完整记录数。错误 -1 不允许进入 i<count 的成功流程。

7. E：返回标签，保留原名字（ex5，课程练习）

需求

getline 读取一行名字，生成标签：空行返回 [anonymous]；否则把空格改为下划线，再在两边加方括号。 显示原名字、标签、原名字中的空格数量。

std::string make_label(std::string name);
std::size_t count_spaces(std::string text);

采用按值参数观察副本。size_t 是适合表达大小和计数的无符号整数类型，使用 std::size_t 时可包含 <cstddef>。

起步步骤

  1. make_label 先检查 name.empty()。
  2. 遍历 name 的有效下标，空格改为 _，修改的是副本。
  3. 返回加括号后的新字符串。
  4. main 把结果接到 label，再显示原 name。
  5. count_spaces 只计 ' '；本题不把所有空白字符都当作空格。

自测

输入 标签 原名字中的空格数
Li Ming [Li_Ming] 1
Han [Han] 0
空行 [anonymous] 0
两个空格 [__] 2

原名字中的空格必须保留。EOF 前完全没有一行输入时，报告输入失败；它和输入了一个有效空行不同。 本题用 ASCII 名字演示，不对多字节字符做字符级替换。

8. F：可以换算法的 calculate（ex6）

对应教材编程练习 10，规则固定为加、减、乘，输入范围用于控制演示数值。

需求与接口

using Operation = double (*)(double, double);
double add(double first, double second);
double subtract(double first, double second);
double multiply(double first, double second);
double calculate(double first, double second, Operation operation);

重复读一对数，每项为 [-1000,1000] 内的有限数。 对每一对调用三种运算，显示 add、subtract、multiply 的结果。 开始下一对时非数字或 EOF 正常结束；缺第二项或超范围报错。

分三阶段写

阶段 1：三个普通函数。 固定输入 2、3，直接调用，得到 5、-1、6。

阶段 2：通过 calculate 调用。 calculate 内只调用 operation(first,second) 并返回。main 给它 add，不能给 add(2,3)。

阶段 3：规则表。 建 Operation operations[]{add,subtract,multiply}，标签数量一致，循环把 operations[i] 传给 calculate。最后加重复输入和范围检查。

自测

输入 预期
2 3 x 5、-1、6
8 2 0 0 x 两组结果；0、0 不是结束标记
-2 3 x 1、-5、-6
x 或直接 EOF 正常结束
2 后 EOF 报不完整的一对
1001 2 报范围错误

所有数组元素都初始化为有效、类型匹配的函数。calculate 的接口前提是有效回调，不允许传 nullptr 然后调用。

9. 选做与过关检查

选做任选其一：

  • 把 B 改写成教材 8 的 a 版，只传原生数组与项数，再比较两个接口。
  • 把 D 改为先读容量再 new[] 创建 Student 数组，检查范围，并在 main 结束使用前 delete[]。保持记录数与容量分开。
  • 手走讲义刻度尺 depth=2 的调用树；分别统计总调用次数和同时等待的最大递归层数。
  • 把 F 加一种同类型的运算并补标签、测试，不修改 calculate 定义。

完成检查：

  • [ ] 结构修改确实写回原对象。
  • [ ] string 标签的修改没有影响原名字。
  • [ ] 可以手走递归进入、基本情形和返回。
  • [ ] 函数指针的声明、初始化、调用分别能解释。
  • [ ] 三种显示接口都只处理完整记录。
  • [ ] 清楚借用的数组元素地址不该 delete。

完成后阅读 参考答案，比较你的接口和边界处理。
