🔬 实验 B：什么情况下才会真的「链接失败」★ 重要

💡 这里有个常见误解：以为「给函数定义末尾多写一个分号」会导致 undefined reference。 先按下面的正确做法做，做完再回头验证那个误解成不成立。

做法：保留原型，把整个函数体删掉。

#include <iostream>
void simon(int);              // 只留声明（说明书）
int main()
{
    simon(3);                 // 调用它
    return 0;
}
// 函数定义整个删掉（厨房没做）

编译，记录报错：
  • 这是哪类错误？（编译期 / 链接期 / 运行期）
  • 报错里的关键词是什么？
  • 用一句话解释：为什么会这样？（提示：声明 vs 定义 = 说明书 vs 实物）
  • 附加验证：把函数定义写回来，只在末尾多加一个 ;，再编译一次。 它能编译通过吗？为什么？
  • 做完恢复原样

🔬 实验 C：原型和定义不一致会怎样（要分两种）

💡 只说「改成 double simon(int); 会怎样」是不够的。实测发现要分两种情况， 而且结果完全不同。请两种都做一遍。

情况 1：只改「返回类型」 —— 原型改成 double simon(int);，定义仍是 void simon(int n)
  • 属于哪类错误？报错关键词？

情况 2：改「参数类型」 —— 原型保持 void simon(int);，把定义改成 void simon(double n)
  • 属于哪类错误？报错关键词？

💡 两种结果不一样，这一条很重要： 返回类型不参与函数签名，所以情况 1 是编译器直接拦下来（编译错误）； 而参数类型是签名的一部分，simon(int) 和 simon(double) 在 C++ 眼里是 两个不同的函数，所以情况 2 编译能过、链接才失败。

练习 3. ⭐ 编写一个 C++ 程序，它使用 3 个用户定义的函数（包括 main()），并生成下面的输出：

Three blind mice
Three blind mice
See how they run
See how they run

其中一个函数要调用两次，该函数生成前两行；另一个函数也被调用两次，并生成其余的输出。

💡 这题是本课的核心。设计思路：

  • 一共 3 个函数：main() + f1() + f2()
  • f1() 输出一行 Three blind mice → 在 main 里调用 2 次
  • f2() 输出一行 See how they run → 在 main 里调用 2 次
  • 两个函数都要写函数原型

想清楚：main() 里应该只有 4 行调用语句，没有 cout。

练习 5. ⭐ 编写一个程序，其中的 main() 调用一个用户定义的函数（以摄氏温度值为参数，并返回相应的华氏温度值）。该程序按下面的格式要求用户输入摄氏温度值，并显示结果：

Please enter a Celsius value: 20
20 degrees Celsius is 68 degrees Fahrenheit.

下面是转换公式：

华氏温度 = 1.8 × 摄氏温度 + 32.0

💡 要点：

  • 函数原型大概长这样：double celsiusToFahrenheit(double);
  • 返回类型用 double（别用 int，否则 20 → 68 是对的，但 21 → 69.8 会被截断）
  • 1.8 和小数点一定要写：如果写成 9 / 5 * c + 32，9/5 会得到 1 而不是 1.8（整数除法！第 3 章细讲）

练习 6. ⭐ 编写一个程序，其 main() 调用一个用户定义的函数（以光年值为参数，并返回对应天文单位的值）。该程序按下面的格式要求用户输入光年值，并显示结果：

Enter the number of light years: 4.2
4.2 light years = 265608 astronomical units.

天文单位是从地球到太阳的平均距离（约 150000000 公里或 93000000 英里），光年是光一年走的距离（约 10 万亿公里或 6 万亿英里）（除太阳外，最近的恒星大约离地球 4.2 光年）。请使用 double 类型（参见程序清单 2.4），转换公式为：

1 光年 = 63240 天文单位

💡 验证：4.2 × 63240 = 265608 ✓ 算出来正好对得上就说明你写对了。 注意 double 默认会打印成 4.2，但如果是 4.0 会打印成 4——第 3 章讲怎么控制。

练习 7. ⭐ 编写一个程序，要求用户输入小时数和分钟数。在 main() 函数中，将这两个值传递给一个 void 函数，后者以下面这样的格式显示这两个值：

Enter the number of hours: 9
Enter the number of minutes: 28
Time: 9:28

💡 要点：

  • 这是不返回值的函数 → 用 void
  • 它接收两个 int 参数：void showTime(int h, int m);
  • 输出格式注意冒号两边不要多空格：Time: 9:28
