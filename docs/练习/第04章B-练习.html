练习 7. William Wingate 从事比萨饼分析服务。对于每个披萨饼，他都需要记录下列信息：

  • 披萨饼公司的名称，可以有多个单词组成。
  • 披萨饼的直径。
  • 披萨饼的重量。

请设计一个能够存储这些信息的结构，并编写一个使用这种结构变量的程序。程序将请求用户输入上述信息，然后显示这些信息。请使用 cin（或它的方法）和 cout。

💡 这题是"数组与字符串"和"结构"两部分的结合，有个经典坑，一定要踩一次：

关键点 1：「公司名称可以有多个单词」 → 不能用 cin >>，必须用读整行的那一类函数。 用 char 数组就是 cin.getline(company, 40)；用 std::string 就是 getline(cin, company)。

关键点 2（本题的坑）：先读数字、再读整行，会踩「换行符残留」陷阱。 请你按程序的提问顺序回答（程序先问直径，再问公司名，最后问重量）。 如果你写成： cpp cin >> diameter; // 只把数字取走 getline(cin, company); // 紧接着读整行 公司名会读到一个空字符串——名称被吞掉了！

为什么？ 你在键盘上敲完数字后按的那个回车键（换行符）还留在输入里， 而 getline 的规则是"读到换行符为止"，它一上来就撞上那个残留的换行符， 于是认为"这一行是空的"。

三种正确做法（任选其一）： 1. 读完数字后，手动把那个换行符吃掉：cin.get(); 2. 把「读数字」和「吃掉换行符」写在一起：(cin >> diameter).get(); 3. 全部用 getline 读进来，再自己把字符串转成数字

测试数据建议：公司名用带空格的（比如 Pizza Hut，或者你自己编一个中文名）， 直径和重量用小数。跑一遍确认公司名没被吞掉。

然后故意试一次错的做法（不加 cin.get();），亲眼看一遍空字符串长什么样。 两种做法都试过，这个坑才算真的学会了。
