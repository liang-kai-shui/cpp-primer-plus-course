开始前：先做小实验，再做整题

这章不要求第一遍就独立写出几十行程序。顺序是：读执行过程 → 跑示例 → 只改一处 → 解释变化 → 自己写小任务。

  • 示例文件保留原样，自己的改动放在 自己新建的 my_code/ 副本里。
  • 不知道怎么写，就先写中文步骤和变量表，不要打开答案整段复制。
  • 本章的部分编程题需要 if 检查错误输入；还没学到时，可以先实现题目约定的正常输入，再读 第 6 章 第 1 节补上校验。最终提交要包含这两部分。
  • 编译、运行、结果正确是三个检查，不能只记“没有报错”。

每个实验按这个小表记录：

我改了哪里 输入或初值 我的预测 实际结果 哪一步解释了差异

不必写很长的感想。写清“i变成3时条件为假，所以不进入”比“循环很神奇”更有用。

A. 闭区间求和 · ex1.cpp

对应原书 5.9 第 1 题，课程增加范围检查：读入下界和上界，均为整数且在 −100000 到 100000 之间，下界不得大于上界；用循环计算包含两端的和。用 long long 累加；非法输入结束并说明原因。

测试：2 9 → 44；5 5 → 5；-2 2 → 0；9 2、x → 拒绝。不要先调用求和公式，先练循环。

怎么起步：先把 2 到 4 算明白。

  1. 先只读入两个整数，打印它们，确认没有把上下界读反。
  2. 在纸上写 2+3+4。循环变量从哪里开始、到哪里停止？这里包含上界，用 <=。
  3. 建一个 long long total=0;，放在循环外。每轮把当前整数加进去。
  4. 暂时在循环体里输出“当前数、当前总和”，应依次看到 2/2、3/5、4/9。确认后删去调试输出。
  5. 加上读取失败、范围无效、下界大于上界的检查。失败后结束，不能继续用未成功读取的值。

卡住时想一想： 上下界相等时也有一个数，循环应执行一次；负数也能相加，不需要换一套循环。

B. 阶乘表 · ex2.cpp

对应原书 5.9 第 2 题，课程改为用户指定上界：输入整数 n（0–100），用 std::array<long double, 101> 保存 0! 到 n!，逐行输出。约定 0!=1，递推为 facts[i] = facts[i-1] * i；不要用整数保存 100!。

测试：0、1、5、100、101、非法输入。100! 约为 9.332622 × 10^157；浮点数有精度限制，不要求输出所有整数位完全精确。

怎么起步：先手写前三个位置。

下标 i 保存的含义 由什么得到
0 0! 约定为1
1 1! 前一个结果乘1
2 2! 前一个结果乘2
  1. 建立固定容量101的数组。容量是能装多少项，n是这次要算到哪里，两者不是同一个意思。
  2. 先给 facts[0] 赋1。接着让i从1到n，使用前一项算当前项。
  3. 计算和输出可以各用一个循环。输出从0开始，别漏掉0!。
  4. 用n=0验证：计算循环应零次，输出循环仍输出一项。
  5. 最后检查n的范围及输入失败。n=100的最后合法下标是100，不是101。

D. 三年销量表 · ex4.cpp

对应原书 5.9 第 6 题：用 int sales[3][12] 接收三年每月的非负销量，输出每年合计和三年总计。输入失败或负数时报错结束；每年合计重新从 0 开始，用 long long 统计总量。

测试：第一年每月 1、第二年每月 2、第三年每月 3 → 12、24、36，总计 72；36 个 0 → 全为 0；中途字母、负数 → 拒绝。无需背诵月份英语名称。

怎么起步：把二维表当作“三张十二格的账单”。

  1. 写出 sales[year][month] 的含义：year取0、1、2；month取0到11。
  2. 先实现一年的12次读取与合计，用每月都是1测试。
  3. 再增加外层的三年循环。每进入新一年，把该年的合计清零；三年总计只在所有循环外清零一次。
  4. 每个数读入后立刻检查是否非负。中途失败时说明读到哪一年哪一月，更容易查错。
  5. 可以输入时合计，也可以先存满再统计；两种都应真正使用题目要求的二维数组。

  5. 再测试立即EOF、立即done、大小写和带标点的词。

输入 4，输出：
...*
..**
.***
****

测试：1、4、30、0、31；每行字符总数必须等于 n。

怎么起步：先把每行的配方写成表格。

n=4，当前行r 点号数量n−r 星号数量r 总宽度
1 3 1 4
2 2 2 4
3 1 3 4
4 0 4 4
  1. 外层循环控制r，从1到n。

  4. 不要在两个打印循环之间换行或加空格，题目只需要点和星。
