A. 转换英文字符 · ex1.cpp

对应原书 6.11 第 1 题：逐字符读取直到 @ 或 EOF；英文大写转小写、小写转大写；数字字符不输出；空白和其他字符保持。@ 本身不输出。用 cctype，并处理 unsigned char 参数。

测试：Ab1! @tail → aB!；立即输入 @ → 无正文；空输入 → 无正文。不要把空格当结束符。

怎么起步：先保留全部字符，再加入规则。

  1. 用 cin.get(ch) 成功一次、输出一次，确认空格和换行都保留。
  2. 添加 @ 检查，必须在输出之前。否则终止标记也会出现在正文里。
  3. 添加数字判断，遇到数字就跳过当前字符，继续读后面的字符。
  4. 其余字符先判断大写或小写，再调用转换函数；其他字符原样输出。
  5. 每次分类前将ch转为 unsigned char，转换函数的结果再转回char输出。

B. 最多十笔数据 · ex2.cpp

对应原书 6.11 第 2 题：用 std::array<double,10> 收集最多十个非负有限数，非数字或 EOF 结束收集；负数或非有限值拒绝。输出数量、平均值、严格高于平均值的数据个数。零笔数据不除以 0。

测试：10 20 30 x → 数量 3、平均 20、高于平均 1；5 5 5 x → 高于平均 0；x → 无数据；十一个 1 → 只收前十个。参考实现用 <cmath> 的 std::isfinite 排除无穷与非数，只需理解检查的目的。

怎么起步：先只存三个数，再恢复容量十。

  1. count从0开始，表示“已经存了几项”，也是下一次可以写入的位置。
  2. 循环先检查还有容量，再尝试读取，成功后才存入数组并累计。
  3. 平均值要等收集完成才能算。若count为0，直接说明没有数据，不能除以0。
  4. 得到平均值后，再遍历已存的前count项，数严格大于平均值的那些项。
  5. 遍历上界用count，不是数组容量；尚未收到的零初值不能当成实际数据。
  6. 加入负数和非有限数检查。普通非数字是本题约定的停止信号，遇到后不要求恢复读取。

D. 分段计算 · ex4.cpp

对应原书 6.11 第 5 题的虚构规则：前 5000 个点数不扣减；随后 10000 个按 10%；再随后 20000 个按 15%；超过 35000 的部分按 20%。反复读入点数，负数或非数字结束；非有限数报错。只按落入某档的那部分计算，不能把总数全乘最高比例。

测试：0、5000 → 0；15000 → 1000；35000 → 4000；38000 → 4600。此题用于练分段逻辑，不是现实税务规则。

怎么起步：先算边界，再算跨档。

先在纸上画四段：0–5000、5000–15000、15000–35000、35000以上。

  1. 5000的结果是0；15000的结果是10000×10%=1000。
  2. 35000再加第二个收费段的20000×15%=3000，总计4000。
  3. 38000只比35000多3000，这3000按20%，再加之前完整两档的4000。
  4. 写else if时从小到大检查上界，每条分支计算“已完整经过的段 + 当前段的超出部分”。
  5. 最后放进输入循环：负数或非数字结束，不要把它们继续代入计算。

F. 文件字符计数 · ex6.cpp

对应原书 6.11 第 8 题，课程增加打开/读取失败检查：整行读入文件名，逐字符数到 EOF，包含空白；输出文本流读到的字符数。说明统计的是文本流字符，而非必然等于磁盘字节数。

测试：空文件 → 0；内容恰好 A b（末尾无换行）→ 3；含空格的文件名可打开；不存在文件 → 报错。不得用 !eof() 作为读取前提。

怎么起步：复用逐字符读取，只换输入源。

  4. 循环后区分正常EOF和读取错误，最后输出计数。
  5. 测试时写清换行是否存在。A b无换行是3个文本流字符，有一个换行则是4个。

若上一条语句用过 cin>>某个数，再用getline读文件名前要处理剩余换行；本题程序直接从getline开始，不需要无缘无故丢弃第一行。
