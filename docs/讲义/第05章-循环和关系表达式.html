第 5 章讲义：循环和关系表达式

教材：《C++ Primer Plus（第 6 版）》第 5 章，PDF 第 143–182 页（书页 125–164）；正文 143–180，复习题 181，编程练习 181–182。 先修：变量、输入输出、数组、字符串；L06–L07 的指针用于解释 *p++，暂时不需要函数或类。 目标：能按执行顺序推演循环，写出不越界的遍历，区别字符输入方式，用二维数组统计数据。 材料说明：章节顺序按原书 5.1–5.6；讲解和示例由课程重新编写。原书程序清单 5.1–5.20 用于对照；涉及求值顺序时按本课程的 C++17 编译环境说明。

1. 循环：让同一套动作反复发生

打印五次问候，可以抄五条输出语句。但换成一千次，或次数来自用户输入，复制就行不通。循环就是“重复执行某段代码，直到条件不成立”。像跑步：每跑一圈，检查是否够了，再决定下一圈。

for (int i = 0; i < 3; ++i) {
    std::cout << i << '\n';
}

for (初始化; 条件; 更新) 的顺序是：初始化一次 → 检查条件 → 执行循环体 → 更新 → 再检查。不能把更新当作第一次循环之前发生。

步骤 i 条件 i < 3 动作
初始化、首次检查 0 真 输出 0
更新后检查 1 真 输出 1
更新后检查 2 真 输出 2
更新后检查 3 假 退出，不再输出

在初始化处声明的 i，只能在这个循环的条件、更新、循环体中使用。若要退出后读它，应先在循环外声明。作用域就是名字能被使用的区域，像某个房间里的标签只在房间内有效。

数组 int a[3] 的下标是 0、1、2，所以遍历条件是 i < 3，写 i <= 3 会访问不存在的 a[3]。若每次加 3，条件 i != 10 可能永远不变成假；想控制上界通常应写 i < 10。

循环体、语句和代码块

循环直接控制一条语句。花括号把多条语句打包成一条复合语句；缩进只是给人看的。

for (int i = 0; i < 3; ++i) {
    std::cout << i;
    std::cout << "!\n";
}

for (...); 中的分号是一个空语句，循环体便为空，后面的代码不属于循环。块内新声明的变量退出块就不可使用；尽量避免在内层再声明同名变量遮住外层变量。

x + 6 只是计算一个值，不修改 x；x = x + 6 或 x += 6 才修改它。表达式算出值，语句要求程序做一步动作；不能看到运算就以为变量发生了变化。

2. 关系表达式：条件怎样得到真假

<、<=、>、>=、==、!= 比较两个值，结果类型是 bool。例如 3 < 5 为 true，3 == 5 为 false。默认输出 bool 是 1 或 0；std::boolalpha 可以输出文字 true / false。

数字用作条件时，0 转为假，非零转为真。if 的详细用法在下一课，本课先理解循环条件。

= 是赋值，== 才是比较。 while (x = 5) 会不断把 5 赋给 x，条件一直为真。编译器警告值得检查，不要为了消除警告给错误赋值加括号。

for (;;) { ... } 省略了条件，它相当于一直为真。先不要在不清楚退出方式时写这种循环。

3. ++：先用旧值，还是先得到新值

++ 把变量加 1；-- 减 1。单独作为语句时，++n; 与 n++; 都把 n 加 1。区别在于这个表达式提供给周围代码的值。

int n = 4;
int a = n++;  // a 得到旧值 4，n 变成 5
int b = ++n;  // n 先变成 6，b 得到新值 6

若 j = 5，条件 ++j < 9 先把 j 加 1再比较；j++ < 9 使用旧值比较，但进入循环体前这次加 1已经完成。不要把“返回旧值”理解成“变量要等很久才修改”。

接回上一课的指针

表达式 意思
*p++ 按 *(p++) 解释：取原来所指的值，再让指针移到下一元素
(*p)++ 增加当前元素；指针不移动
*++p 先移动指针，再取新位置的值

这些操作仍要遵守数组边界。示例 03 把每种操作拆成单独语句，方便画出指针的位置。

副作用与求值顺序

副作用是表达式除了算出值，还修改了程序状态，比如 n++ 修改 n。知道运算符优先级，只能知道表达式怎样分组，不能据此断定所有子表达式从左到右执行。

// 错误示意，只分析，不运行：
// int result = i++ + ++i;

上面两个修改没有规定的先后顺序，行为未定义，不能把某次运行的输出当作规则。把修改拆成多条语句最容易核对。原书 5.1.6 使用较早的标准背景，C++17 改变了部分求值顺序规则，因此不能把书中的赋值示例一概套用到所有标准；本课不靠复杂自增表达式完成实际任务。标准的求值顺序规则

复合赋值与逗号（5.1.9–5.1.11）

+=、-=、*=、/=、%= 把运算与赋值合起来。对于这里的简单整数变量，total += value 等价于 total = total + value；整数 /= 仍是整数除法，%= 用于整数。

逗号运算符先执行左边，再执行右边，整个表达式的值取右边：

int x = 0;
int y = (x = 3, x + 2); // x 为 3，y 为 5

int a = 1, b = 2; 的逗号分隔声明，不是上面的逗号运算符。逗号可以放在 for 的更新部分同时更新两个变量，但初学时先用循环体内的两条语句，容易检查。

4. 字符串：比较内容与遍历边界

两个字符数组用 ==，通常会先转换成指针，比较的是地址，没有逐个比较字符。C 风格字符串比较内容，用 <cstring> 的 std::strcmp(a, b)：0 表示相等，小于 0 / 大于 0 表示顺序；不要依赖结果恰好是 −1 或 1。

std::string 已经提供内容比较，可以写 word == "done"，也可以用 < 比较字典顺序。字符串的字典顺序不是字符串中数字的数值顺序；例如 "10" < "2"。

反向遍历容易在空字符串时写错。size() 返回无符号长度，直接写 word.size() - 1 可能在长度为 0 时下溢。采用下面的形式：

for (std::size_t i = word.size(); i > 0; --i) {
    std::cout << word[i - 1];
}

长度为 0，一次也不进入；长度为 3，访问下标 2、1、0。示例 04 用 getline 允许空行和空格。这里处理的是单字节 ASCII 文本；反转 UTF-8 中文的字节不能得到正确的中文字序。

5. while 和 do...while：选择检查时机

while 先检查条件，真才执行；它适合“读到结束”“累计直到达到目标”等次数事先未知的事情。

int n = 3;
while (n > 0) {
    std::cout << n << ' ';
    --n; // 缺少这一步，条件可能永远为真
}

do...while 先执行循环体，再检查条件，正常执行时至少进入一次。像先问一次菜单，再决定要不要继续。结尾有必需的分号。

int n = 0;
do {
    std::cout << n << '\n';
} while (n > 0);

上面仍打印一次 0；对应 while (n > 0) 则一次也不打印。三种循环并非互相替代的口号：固定次数优先考虑 for，输入驱动优先考虑 while，必须先做一次再判断时考虑 do...while。

原书的计时和类型别名（5.2.2）

<ctime> 中的 std::clock()、std::clock_t 与 CLOCKS_PER_SEC 用于估算程序消耗的处理器时间：两次读数的差除以每秒刻度，得到秒数；应检查 clock() 是否返回失败值。它不保证等同于现实经过的钟表时间。原书用循环等待演示 while，会持续占用处理器，不适合用作日常等待方案。

typedef std::clock_t Tick; 为已有类型取一个别名，像给同一人添昵称，没有创造新的不同类型；现代写法可用 using Tick = std::clock_t;。这些是阅读补充，不要求写计时程序。

6. 范围 for：从每个元素取值

int scores[]{70, 80, 90};
for (int score : scores) {
    std::cout << score << '\n';
}

冒号右边是要遍历的容器或数组；左边的变量依次得到元素。这里 score 是副本，修改它不会改数组。若写 int& score，它是当前元素的别名，修改它会改数组；这就是引用的最小用法，完整规则留到 L12。

需要下标、跳过部分元素或同时操作两组数据时，普通 for 仍合适。范围循环不是“更短就永远更好”。

7. 文本输入：先区分“读什么”，再判断“读到了吗”

输入方法 空格、制表符、换行 成功判断
std::cin >> ch（char） 默认跳过 把提取表达式用作条件
std::cin.get(ch) 保留 把 get(ch) 的返回流用作条件
std::cin.get() 保留 返回字符或 EOF 标记，先检查再转换 
char ch;
while (std::cin.get(ch)) {
    std::cout << ch;
}

循环条件尝试读取一个字符，成功才进循环体，不会在读取失败后重复使用旧的 ch。get(ch) 与 get() 同名但参数和返回值不同，这是原书 5.5.3 引出的函数重载；这里只需按调用形式区别。

EOF 表示输入结束，不是正文里某个可见字符。无参数 get() 返回的类型需要同时容纳字符和结束标记；若先保存到 char，可能丢掉区别。示例 09 用 std::char_traits<char>::int_type 接住返回值，与 eof() 比较，确认有字符后才转成 char。原书使用 int 与 EOF 演示同一思路，别直接硬编码 −1。

不要写 while (!std::cin.eof()) 再在循环体内读：EOF 状态通常在尝试读取后才更新，检查过早会多做一次。输入失败还可能是类型不匹配，不只有 EOF；下一课详细讲处理。

示例 07、08 以 # 为结束哨兵（专门约定的结束字符，不计入统计）；09 读到 EOF。给 07、08 输入 A b、换行、#，07 数到 2，08 数到 4：一个空格和一个换行也算字符。

示例条件中的 && 表示“并且”：先成功读到字符，再检查它不是哨兵，才进入循环体。若读取失败，后面的字符比较不会执行；完整的逻辑运算和短路规则在 L09 展开。

Windows 交互终端通常可以在空行按 Ctrl+Z、再回车产生 EOF，具体由终端决定。也可以用文件输入获得可重复的结果：

g++ -std=c++17 -Wall -Wextra -pedantic 示例代码/05_循环和关系表达式/09_get_eof.cpp -o example.exe
cmd /c "example.exe < 示例代码\05_循环和关系表达式\text_sample.txt"

PowerShell 自己不支持这种 < 输入重定向，所以这里由 cmd 执行。统计文本字符时，本课按文本流读出的字节计数；Windows 文本模式会把文件中的 CRLF 换行转换为 \n，结果不一定是磁盘文件字节数。

8. 嵌套循环与二维数组

嵌套就是一个循环体里面再放一个循环。像班级点名：外层选班级，内层逐个点这个班的学生。每换一个班，内层要从第一个学生重新开始。

int sales[2][3]{{10, 20, 30}, {40, 50, 60}};
for (int row = 0; row < 2; ++row) {
    int row_total = 0;
    for (int col = 0; col < 3; ++col) {
        row_total += sales[row][col];
    }
    std::cout << row_total << '\n'; // 60、150
}

int sales[2][3] 是两个“含三个 int 的数组”组成的数组。第一个下标选行，第二个选列；这里行只允许 0–1，列只允许 0–2。花括号可以按行初始化，缺少的元素会被置零。

row_total 在外层循环体里初始化，每行重新从 0 开始；如果放到外面却不重置，第二次输出会是前两行累计。要算每一列，则外层遍历列，内层遍历行，仍访问 sales[row][col]，不能为了换遍历顺序就随意交换下标。

  • [ ] 不靠猜编译器输出解释未定义行为。
  • [ ] 空字符串反向遍历不产生非法下标。

  • [ ] 能独立写二维数组的行合计与列合计。
