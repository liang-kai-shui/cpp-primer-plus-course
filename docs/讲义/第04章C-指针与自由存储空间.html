第 4 章 C · 指针与自由存储空间

教材：4.7，PDF 阅读器第 115–124 页（书页 97–106）。先学完第 4 章 A 的数组，再读本课。 本课目标：看懂地址、指针和解引用；能安全地使用 new / delete 及 new[] / delete[]；知道什么时候不该用裸指针管理内存。 材料说明：本讲义按原书 4.7 组织，示例与练习由课程自编，并非书中程序清单或课后题的逐字版本。原书程序清单 4.14–4.18 在上述页码内，可对照阅读。

1. 从一次真实的困惑开始：letter_grade + 1

char letter_grade[] = "ABCD";
std::cout << letter_grade + 1;  // 输出 BCD，而不是把 A 变成 B

数组名 letter_grade 在这条表达式里转换成指向第一个元素的指针；+ 1 得到指向第二个元素的指针。cout 从那里开始打印 C 风格字符串，于是看到 BCD。这先展示现象；指针加法的完整规则留在第 4 章 D。

想得到第二个字符，写 letter_grade[1]。想把第一个字符改成 'B'，写 letter_grade[0] = 'B'。地址加 1和字符值加 1是两件事。

2. 地址、指针变量、所指的值

可以把一个 int 变量想成一间放数据的房间，地址是门牌号，指针变量则是记着门牌号的纸条。纸条本身也占空间，但纸条不是那间房。

int score = 90;
int* p = &score;
表达式 含义 此例中的结果
score 变量里的值 90
&score score 的地址 一个地址，具体数字每次运行可能不同
p 指针变量保存的地址 与 &score 相同
*p 沿地址找到的 int 值，叫解引用 90
&p 指针变量 p 自己的地址 通常与 p 不同 
score: [ 90 ]  ← p 存着 score 的地址
        ↑
        *p 读写的就是这个 int

*p = 95; 修改的是 score，之后两者读出来都是 95。int* p 中的 * 表示“声明一个指向 int 的指针”；*p 在表达式中表示“取所指对象”。两处写法相同，作用不同。

类型也要配对：int* 应指向 int，double* 应指向 double。指针并非“任意地址都能当任意数据读”。

原书 4.7.3 还强调：普通整数不是可随意赋给指针的地址。不要靠强制转换把猜测的数字当成有效指针；指针应来自现存对象的地址或合法的分配结果。

⚠️ int* a, b; 只让 a 成为指针，b 仍是普通 int。初学时每行只声明一个变量，最不容易看错。

3. nullptr 与危险指针

指针可以暂时不指向对象，C++11 用 nullptr 表示这种状态：

int* p = nullptr;
if (p != nullptr)
    std::cout << *p;

不能解引用 nullptr。 也不能先写 int* p; 就马上用 *p：此时 p 没有被初始化，里面不是可靠的地址。下面这些都是错误示范，示例程序不会真的执行它们：

// int* bad; *bad = 5;        // 未初始化
// int* empty = nullptr; *empty = 5; // 空指针

检查 p != nullptr 只能排除空指针，不能证明它指向的对象仍然活着。已释放或已离开生存期的对象还会留下悬空指针。

4. new / delete：动态创建一个对象

普通局部变量离开所在代码块就结束生存期。new 在自由存储空间创建对象，返回指向它的指针；这个对象需要按规则释放。

int* p = new int{42}; // 创建并初始化一个 int
std::cout << *p;      // 42
delete p;             // 结束这个对象的生存期并释放对应存储空间
p = nullptr;          // 避免继续误用这个变量保存的旧地址

可以把 new 想成借来一间房，delete 是退还。仅把 p 设成 nullptr 不会退还房间，要先 delete。delete p 之后不能再读 *p，也不能再次 delete p；把 p 置空只保护这一个指针变量，其他保存同一旧地址的指针仍然悬空。

new 可能因内存不足而失败，通常以异常报告。本课先把正常路径和配对释放学会，不要把动态分配当成每个变量的默认写法。见 03_new_delete.cpp。

5. new[] / delete[]：动态创建数组

数组长度若要在运行时由输入决定，教材使用 new[]：

int count = 3;                 // 实际输入时先检查 count > 0
int* scores = new int[count]{}; // {} 把所有元素初始化为 0
scores[0] = 80;
scores[1] = 90;
scores[2] = 100;

delete[] scores;              // 数组必须用 delete[]
scores = nullptr;

scores[i] 可按下标访问，但指针不保存数组长度。边界仍由你维护。new int{42} 配 delete；new int[count]{} 配 delete[]。不要混用，也不要把 new[] 得到的地址交给 delete。完整示例 04_dynamic_array.cpp 会按输入长度求和。

得到资源 释放方式
new int{42} delete p
new int[count]{} delete[] p
普通局部变量 int x 不手动 delete

6. 实际写程序时如何选择

本课学习裸指针和手动释放，是为了理解教材、读懂旧代码和识别错误。需要运行时长度的数组时，优先考虑 std::vector，它会管理自己的存储空间；第 4 章 D 会正式使用。单个动态对象以后也会学到智能指针。

动手前先回答三问：指针当前指向谁？所指对象还活着吗？谁负责释放？如果答不清，先不要解引用或释放。

7. 过关检查

  1. 不看资料写出 int x{7}; int* p{&x};，说明 p、*p、&p 分别是什么。
  2. 能指出未初始化指针、空指针和悬空指针的危险。
  3. 能给 new 与 new[] 选择正确的释放方式，并解释为什么 p = nullptr 不能代替 delete。
  4. 完成本课练习后再看参考答案。
