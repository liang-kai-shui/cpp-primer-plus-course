## 3. A：调和平均数（ex1）

对应教材编程练习 1，课程限制输入为正常范围的正数。

### 需求

重复读取一对数 x、y，输出 `mean=` 加调和平均数：

```text
2xy / (x+y)
```

- 任意一个数为 0 时结束，不计算这一对。
- 在读下一对的第一个数时遇到非数字或 EOF，正常结束。
- 已有第一个数却读不到第二个数，报告不完整输入并结束。
- 非结束输入必须是大于 0、至多 1000000 的有限数；否则报告错误。

### 建议接口

```cpp
double harmonic_mean(double first, double second);
```

函数只计算；循环、输入、范围检查放 main。返回值要用到输出表达式中。

### 先手算

2、6：分子 24，分母 8，结果 3。5、5 的结果应为 5。

### 起步步骤

1. 先让 main 用固定的 2、6 调用计算函数。
2. 确认得到 3，再改为输入。
3. 每轮先读第一个数，再检查第二个数是否读成功。
4. 检查结束标记，再检查有效范围，最后调用。
5. 返回循环开头，等待下一对。

不要先计算再检查零或非法范围。公式中 `/` 的分母必须合适。

### 自测表

| 输入 | 预期 |
|---|---|
| `2 6 5 5 0 8` | mean=3、mean=5，然后结束 |
| `8 0` | 不输出平均数 |
| `x` 或直接 EOF | 正常结束 |
| `2 x` 或只有 `2` 后 EOF | 报不完整的一对 |
| `-1 3` | 报范围错误 |

## 4. B：最多十项成绩（ex2）

对应教材编程练习 2，练习“容量、已用长度、返回值”。

### 需求

最多读入 10 项成绩。非数字或 EOF 停止读入；已读成绩保留。有效成绩在 0–1000 之间，超范围立即报告错误。
显示已用项，计算平均值。没有成绩时输出 `No scores`，不能除以 0。

建议接口：

```cpp
int fill_scores(double scores[], int capacity);
void show_scores(const double scores[], int count);
double mean_score(const double scores[], int count);
```

fill 返回已用项数；错误返回 -1。mean 的前提是 count>0；main 先分支检查，再调用。

### 起步步骤

1. 声明 `double scores[10]{}`，capacity 是 10，count 起始是 0。
2. 循环条件先检查 count 是否小于 capacity，避免写到第 11 项。
3. 读到合法成绩后存 `scores[count]`，再增加 count。
4. 返回 count，main 接住。count<0 时停止后续操作。
5. 显示函数只遍历 count 项。
6. mean 累加这 count 项，最后除以 count。

### 手算并测试

| 输入 | 已用长度 | 预期平均值 |
|---|---|---|
| `10 20 30 x` | 3 | 20 |
| `0 x` | 1 | 0，不是没有输入 |
| `x` | 0 | No scores |
| 十项全为 100，后接 999 | 10 | 100；容量满后不继续读取 |
| `-1` 或 `1001` | 错误 | 不显示成功统计 |

**提示：** show 的参数为什么用 const？mean 是否有必要修改任何成绩？

## 5. C：反转全部，再反转中间（ex3）

改编自教材编程练习 6，本课容量固定为 6。

### 需求

读至多 6 个数，非数字或 EOF 结束，数字范围为 [-1000000,1000000] 且有限。显示原序列；反转全部后显示；保持两端不动，再反转中间部分后显示。

```cpp
int fill_values(double values[], int capacity);
void show_values(const double values[], int count);
void reverse_values(double values[], int count);
```

fill 返回 count 或 -1。reverse 没有返回值，通过数组地址修改元素。

### 先画交换位置

对 count=5，交换 (0,4)、(1,3)，中间下标 2 不动。
left 从 0 到 count/2 之前，right 等于 count-1-left。

不要让左右相交后继续交换，否则刚反转的结果可能又被反转回去。

### 起步步骤

1. 先用固定数组练反转，不接输入。
2. 用 temporary 暂存左值，再把右值放到左边，最后写回右边。
3. count=0、1 时循环都不进入。
4. main 调 reverse(values,count) 反转全部。
5. 只有 count>2 时，中间起点是 values+1，中间长度是 count-2。
6. 两次操作之间都显示，方便发现哪一步出错。

### 预期变化

```text
输入：1 2 3 4 5 x
原序列：1 2 3 4 5
反转全部：5 4 3 2 1
反转中间：5 2 3 4 1
```

再测没有输入、一项、两项、六项。两项时只有第一次交换，两端固定后的第二次不操作。

## 6. D：让填充函数返回区间末尾（ex4）

对应教材编程练习 7 的指针范围版本。

**约定很重要：** fill 返回的是已填部分的末尾后一个位置，供 `[begin,used_end)` 使用。不要把它理解成最后一个已填元素。

### 需求与接口

容量 5；数值范围同 C。非数字或 EOF 正常结束填充；范围错误返回 nullptr，并由 main 停止统计。

```cpp
double* fill_range(double* begin, double* end);
void show_range(const double* begin, const double* end);
double sum_range(const double* begin, const double* end);
```

这里 begin、end 必须属于同一个有效数组范围，end 可以是末尾后一个位置。

### 起步步骤

1. current 从 begin 开始。
2. current!=end 且读入成功时，检查数字，写 `*current=value`。
3. 写完后 `++current`。循环结束返回 current。
4. main 把返回值接到 used_end，先判断是否 nullptr。
5. 显示、求和都从 begin 遍历到 used_end 之前。
6. `used_end-begin` 是项数；不能对 unrelated pointers 做这个减法。

### 用三项输入画地址

```text
数组下标：  0    1    2    3    4
存入：     10   20   30
begin ─────┘              └── used_end（下标3）
```

总和 60，count=3。没有输入时 used_end==begin，不是错误 nullptr；sum 应返回 0。

自测：`10 20 30 x`、`x`、五项、只有一项、超范围数字。输出项数必须与实际输入相同，不能总报 5。

## 7. E：把二维数组交给函数（ex5，课程练习）

### 需求

输入一个 2 行 3 列整数表，每项 [-1000,1000]。必须完整读到六项，否则报告错误。输出全表总和，以及三列各自的和。

```cpp
long long sum_matrix(const int values[][3], int rows);
long long sum_column(const int values[][3], int rows, int column);
```

columns 固定是 3，调用者保证 column 在 0–2。使用 const，因为求和不改表格。

### 手算

```text
1 2 3
4 5 6
```

全表 21；第 0 列 1+4=5，第 1 列 2+5=7，第 2 列 3+6=9。

### 起步步骤

1. main 用两层循环完整读六项并检查范围。
2. sum_matrix 用外层行、内层列累加。
3. sum_column 只循环行，列下标固定为传入的 column。
4. main 调三次 sum_column，或用 column 从 0 到 2 的循环调用。

再测六项全 0、六项全负数、少一项、出现 1001。不要把原型写成 `int**`：二维原生数组按行连续存储，该形参指向一行数组。

## 8. F：在 C 风格字符串中替换字符（ex6）

对应教材复习题 8 的动手版本。

### 需求

读入一行文本（允许空行，最多 200 个字节），再读取两个非空白字符 old、replacement。将每个 old 替换为 replacement，返回匹配位置数，显示 count 和新文本。

```cpp
int replace_char(char text[], char old_char, char replacement);
```

输入数组 `char text[201]`，第 201 个位置为结尾零字符预留空间；使用 cin.getline。超长或不完整输入应报告错误。

这里按 char 的字节操作，先用 ASCII 字母测试；200 个字节不等于 200 个汉字。
使用 `>>` 读取两个字符会跳过空白，因此本题不要求替换空格。

### 起步步骤

1. 从下标 0 开始，只要 text[i] != '\0' 就继续。
2. 相等时赋 replacement，同时增加 count。
3. 不替换终止零字符；循环结束返回 count。
4. main 接住返回值，输出 count 与 text。

### 自测

| 文本；字符 | 预期 |
|---|---|
| banana；a o | bonono，count=3 |
| abc；x z | abc，count=0 |
| 空行；a b | 空文本，count=0 |
| aaa；a a | aaa，count=3，统计的是匹配位置 |
| 正好 200 个 a；a b | 成功，count=200 |
| 201 个 a | 报超长输入错误 |

为什么返回 int 而不是 `char*`？调用者已经握有原数组，这里需要的新信息是匹配位置数。
