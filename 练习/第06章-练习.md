## 任务 3：预测和找错

```cpp
// A：独立片段
int n = 7, calls = 0;
bool a = (n > 0) || (++calls > 0);
bool b = (n < 0) && (++calls > 0);
std::cout << a << ' ' << b << ' ' << calls;

// B：独立片段
char command = 'a';
switch (command) {
case 'a': std::cout << "A";
case 'b': std::cout << "B"; break;
default: std::cout << "?";
}
```

A、B 各输出什么？若 B 希望只输出 A，应怎样修正？另回答：`while (in >> value)` 与 `while (in.good()) { in >> value; ... }` 为什么不同？

## 任务 4：编程

### A. 转换英文字符 · `ex1.cpp`

对应原书 6.11 第 1 题：逐字符读取直到 `@` 或 EOF；英文大写转小写、小写转大写；数字字符不输出；空白和其他字符保持。`@` 本身不输出。用 cctype，并处理 unsigned char 参数。

测试：`Ab1! @tail` → `aB! `；立即输入 @ → 无正文；空输入 → 无正文。不要把空格当结束符。

### B. 最多十笔数据 · `ex2.cpp`

对应原书 6.11 第 2 题：用 `std::array<double,10>` 收集最多十个非负有限数，非数字或 EOF 结束收集；负数或非有限值拒绝。输出数量、平均值、严格高于平均值的数据个数。零笔数据不除以 0。

测试：`10 20 30 x` → 数量 3、平均 20、高于平均 1；`5 5 5 x` → 高于平均 0；`x` → 无数据；十一个 1 → 只收前十个。参考实现用 `<cmath>` 的 `std::isfinite` 排除无穷与非数，只需理解检查的目的。

### C. 字符菜单 · `ex3.cpp`

对应原书 6.11 第 3 题并增加退出方式：提供 c（查看课程）、p（查看进度）、t（练习提示）、g（问候）、q（退出）；支持大写，未知命令提示后重新等待。必须使用 switch，退出须结束整个循环。

测试：`x C p Q`；立即 EOF；立即 q。菜单按字符读取，输入单词会被拆成多个命令，不要求实现整行命令解析。

### D. 分段计算 · `ex4.cpp`

对应原书 6.11 第 5 题的**虚构规则**：前 5000 个点数不扣减；随后 10000 个按 10%；再随后 20000 个按 15%；超过 35000 的部分按 20%。反复读入点数，负数或非数字结束；非有限数报错。只按落入某档的那部分计算，不能把总数全乘最高比例。

测试：0、5000 → 0；15000 → 1000；35000 → 4000；38000 → 4600。此题用于练分段逻辑，不是现实税务规则。

### E. 按首字母分类单词 · `ex5.cpp`

对应原书 6.11 第 7 题：逐词读到恰好等于 `q` 的词；按首字节分为英文字母元音开头、其他英文字母开头、其他开头。大小写都识别，q 不统计；用 cctype 判断字母，元音为 a/e/i/o/u。

测试：`Apple boat 42 !x egg q` → 2、1、2；`q` → 全为 0；EOF 也结束。`queen` 是普通词；本题约定单字节英文文本，不做中文分类。

### F. 文件字符计数 · `ex6.cpp`

对应原书 6.11 第 8 题，课程增加打开/读取失败检查：整行读入文件名，逐字符数到 EOF，包含空白；输出文本流读到的字符数。说明统计的是文本流字符，而非必然等于磁盘字节数。

测试：空文件 → 0；内容恰好 `A b`（末尾无换行）→ 3；含空格的文件名可打开；不存在文件 → 报错。不得用 `!eof()` 作为读取前提。
