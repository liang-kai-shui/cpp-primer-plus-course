## 任务 3：找错误，只分析危险语句

1. `int a[3]{}; for (int i=0; i<=3; ++i) a[i]=i;`
2. `int n=1; while(n<4); { ++n; }`
3. `while(!std::cin.eof()) { std::cin.get(ch); ++count; }`
4. `char a[]="hi", b[]="hi";` 后用 `a == b` 判断文字相等。
5. `int result = i++ + ++i;`，声称“我的电脑打印某值，所以结果确定”。

逐项写明：哪里错、可能的后果、怎样修改。不要实际运行越界或未定义行为来验证。

## 任务 4：编程（每题都有边界测试）

### A. 闭区间求和 · `ex1.cpp`

对应原书 5.9 第 1 题，课程增加范围检查：读入下界和上界，均为整数且在 −100000 到 100000 之间，下界不得大于上界；用循环计算包含两端的和。用 `long long` 累加；非法输入结束并说明原因。

测试：`2 9` → 44；`5 5` → 5；`-2 2` → 0；`9 2`、`x` → 拒绝。不要先调用求和公式，先练循环。

### B. 阶乘表 · `ex2.cpp`

对应原书 5.9 第 2 题，课程改为用户指定上界：输入整数 `n`（0–100），用 `std::array<long double, 101>` 保存 0! 到 n!，逐行输出。约定 0!=1，递推为 `facts[i] = facts[i-1] * i`；不要用整数保存 100!。

测试：0、1、5、100、101、非法输入。100! 约为 `9.332622 × 10^157`；浮点数有精度限制，不要求输出所有整数位完全精确。

### C. 两种增长方式 · `ex3.cpp`

对应原书 5.9 第 4 题，独立改写：两人初始各有 100 个点数。A 每年增加初始点数的 10%；B 每年增加当前点数的 5%。用循环找 B 第一次严格超过 A 的年份，并输出当时两人的点数。点数只是数学模型。

检查：第 1 年分别 110、105；第 27 年第一次超过。若两人恰好相等，是否该结束？

### D. 三年销量表 · `ex4.cpp`

对应原书 5.9 第 6 题：用 `int sales[3][12]` 接收三年每月的非负销量，输出每年合计和三年总计。输入失败或负数时报错结束；每年合计重新从 0 开始，用 `long long` 统计总量。

测试：第一年每月 1、第二年每月 2、第三年每月 3 → 12、24、36，总计 72；36 个 0 → 全为 0；中途字母、负数 → 拒绝。无需背诵月份英语名称。

### E. 单词计数 · `ex5.cpp`

对应原书 5.9 第 9 题：用 `std::string` 逐词输入，遇到恰好等于 `done` 的词结束，`done` 不计数；没有哨兵时 EOF 也能正常结束。大小写敏感，`Done` 和 `done!` 是普通词。

测试：`one two done three` → 2；`done` → 0；`Done done! done` → 2；空输入 → 0。

### F. 右对齐三角形 · `ex6.cpp`

对应原书 5.9 第 10 题：输入行数 n（1–30），用嵌套循环打印宽度为 n 的图形，每行左侧为点号，右侧为星号，第 r 行有 r 个星号。

```text
输入 4，输出：
...*
..**
.***
****
```

测试：1、4、30、0、31；每行字符总数必须等于 n。
