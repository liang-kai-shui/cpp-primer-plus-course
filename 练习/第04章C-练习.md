## 任务 3：自己写两个程序

### 编程 A：一个动态数值

创建一个动态 `double`，初始化为 `2.5`，通过指针把它改为原值的两倍，打印结果，正确释放并把指针置空。文件名建议 `ex1.cpp`。**检查点**：输出应为 `5`；不能在释放后再读所指对象。

### 编程 B：运行时长度的分数数组

输入人数 `n`，只接受 `1–100`。用 `new[]` 创建并值初始化 `n` 个 `int`，再读取 `n` 个分数，打印平均分，正确释放。输入错误时要避免除以 0 或越界。文件名建议 `ex2.cpp`。

测试：`3` 人，分数 `80 90 100`，平均分应是 `90`。再试 `0` 和非数字输入。
